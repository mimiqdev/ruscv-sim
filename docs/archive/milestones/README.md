# Archived Milestones

This directory contains completed and explicitly superseded milestone plans with their historical outcomes.

Archived files are not active plans. They may describe component-level completion that predates end-to-end integration or ACT4 verification. Consult `../../dev-plan.md` for the only active milestone.

## Rolling process

1. `docs/dev-plan.md` contains exactly one active milestone.
2. Once all acceptance criteria are verified, move that plan here as completed.
3. If planning is deliberately reset, archive the replaced plan as superseded without claiming completion.
4. Add completion evidence or the supersession reason and known limitations to the archived record.
5. Promote the next milestone into `docs/dev-plan.md`.
