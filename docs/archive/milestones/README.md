# Archived Milestones

This directory contains completed milestone plans and their historical outcomes.

Archived files are not active plans. They may describe component-level completion that predates end-to-end integration or ACT4 verification. Consult `../../dev-plan.md` for the only active milestone.

## Rolling process

1. `docs/dev-plan.md` contains exactly one active milestone.
2. Once all acceptance criteria are verified, move that plan here.
3. Add completion evidence and known limitations to the archived record.
4. Promote the next milestone into `docs/dev-plan.md`.
