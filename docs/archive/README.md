# Documentation Archive

This directory preserves superseded plans, completed milestones, historical reports, and replaced designs. Archived content is context only and is not an active product commitment.

## Categories

- [`milestones/`](milestones/) — completed or superseded milestone records.
- [`plans/`](plans/) — obsolete standalone plans that were never promoted as current work.
- [`designs/`](designs/) — replaced architecture and design baselines.
- [`reviews/`](reviews/) — historical code-review records and obsolete action assignments.
- [`research/`](research/) — full historical studies whose conclusions or roadmaps are no longer current.
- [`reference/`](reference/) — old implementation notes, format analyses, and dependency snapshots.
- Sprint documents in this directory — historical planning records predating the rolling-plan workflow.
