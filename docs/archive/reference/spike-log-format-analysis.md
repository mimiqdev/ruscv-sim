## 概述

本文档记录了 RISC-V ISA Simulator (Spike) 的 `--log-commits` 日志输出格式，用于指导 ruscv-sim 的日志格式对齐。

---

## Spike 日志选项

```bash
# 基本日志 (-l)
spike -l <elf>

# 提交日志 (推荐，包含寄存器/内存变化)
spike --log-commits -l <elf>

# 输出到文件
spike --log-commits --log=output.log <elf>
```

## 日志格式详解

### 1. 普通指令行（无 --log-commits）

**格式：**
```
core   <hartid>: <pc> (<opcode>) <mnemonic> <operands>
```

**示例：**
```
core   0: 0x0000000000001000 (0x00000297) auipc   t0, 0x0
core   0: 0x0000000080000000 (0x00000093) li      ra, 0
core   0: 0x000000008000000c (0x0021c863) blt     gp, sp, pc + 16
```

**字段说明：**
| 字段 | 含义 | 宽度 |
|------|------|------|
| `core   <hartid>` | 核心标识， hart ID | 固定宽度 |
| `<pc>` | 程序计数器，16位十六进制 | 18字符 |
| `<opcode>` | 机器码，8位十六进制 | 10字符（含括号） |
| `<mnemonic>` | 指令助记符 | 8字符右对齐 |
| `<operands>` | 操作数 | 可变 |

---

### 2. 提交行（带 --log-commits）

**格式：**
```
core   <hartid>: <privilege> <pc> (<opcode>) [<changes>]
```

**示例（算术指令）：**
```
core   0: 3 0x0000000080000000 (0x00000093) x1  0x0000000000000000
core   0: 3 0x0000000080000004 (0x00100113) x2  0x0000000000000001
core   0: 3 0x0000000080000010 (0x002080b3) x1  0x0000000000000001
```

**示例（加载指令）：**
```
core   0: 3 0x0000000080000008 (0x00052083) x1  0x0000000012345678 mem 0x00000000800000c0
```

**示例（存储指令）：**
```
core   0: 3 0x0000000080000010 (0x00152023) mem 0x0000000080000180 0x12345678
```

**示例（分支指令 - 无寄存器变化）：**
```
core   0: 3 0x0000000080000014 (0x08709263)
```

---

### 3. 字段对齐规范

#### PC 地址
- **宽度:** 18 字符（包含 "0x" 前缀）
- **格式:** `0x0000000000001000`
- **十六进制:** 小写，零填充

#### 机器码
- **宽度:** 10 字符（包含括号）
- **格式:** `(0x00000297)`
- **注意:** 压缩指令显示为 4 字符：`(0x8082)`

#### 寄存器
- **格式:** `x<num>  <value>`
- **寄存器号:** 1-2 字符（x0-x31）
- **值:** 18 字符，零填充
- **分隔:** 2 个空格

**示例：**
```
x5  0x0000000000001000     (寄存器 + 2空格 + 值)
x10 0x0000000000000000
x11 0x0000000000001020
```

#### 内存访问
- **加载:** `mem <addr>`
- **存储:** `mem <addr> <value>`
- **地址:** 18 字符
- **值:** 8 字符（word）或 16 字符（dword）

---

### 4. 特权模式标识

提交行开头的数字表示特权模式：

| 值 | 模式 |
|----|------|
| 3 | Machine (M) |
| 1 | Supervisor (S) |
| 0 | User (U) |

**示例：** `core   0: 3 ...` 表示 Machine 模式

---

### 5. 特殊标记

| 标记 | 含义 | 示例 |
|------|------|------|
| `>>>>` | 标签/注释行 | `>>>>  wait_tx_ready` |
| `H` | 特殊状态 | `Hcore   0: ...` |
| `e` | 异常 | `ecore   0: ...` |
| `l` | 加载完成 | `lcore   0: ...` |
| `o` | 存储完成 | `ocore   0: ...` |

## 指令类型样本

### 算术指令
```
core   0: 3 0x0000000080000000 (0x00000093) x1  0x0000000000000000     # li
core   0: 3 0x0000000080000004 (0x00100113) x2  0x0000000000000001     # addi
core   0: 3 0x0000000080000010 (0x002080b3) x1  0x0000000000000003     # add
core   0: 3 0x000000008000000c (0x123453b7) x7  0x0000000012345000     # lui
core   0: 3 0x0000000080000010 (0x6783839b) x7  0x0000000012345678     # addiw
```

### 分支指令
```
core   0: 3 0x000000008000000c (0x0021c863)                             # blt - 无变化
core   0: 3 0x0000000080000018 (0xff5ff06f)                             # j - 无变化
```

### 加载指令
```
# ld - 8字节加载
core   0: 3 0x000000000000100c (0x0182b283) x5  0x0000000080000000 mem 0x0000000000001018

# lw - 4字节加载
core   0: 3 0x0000000080000008 (0x00052083) x1  0x0000000012345678 mem 0x00000000800000c0

# lbu - 字节加载（零扩展）
core   0: 3 0x0000000080000058 (0x00554183) x3  0x0000000000000060 mem 0x0000000010000005
```

### 存储指令
```
# sw - 4字节存储
core   0: 3 0x0000000080000010 (0x00152023) mem 0x0000000080000180 0x12345678

# sb - 字节存储
core   0: 3 0x000000008000000c (0x00250023) mem 0x0000000010000000 0x48
```

### CSR 指令
```
core   0: 3 0x0000000000001008 (0xf1402573) x10 0x0000000000000000     # csrr mhartid
```

### 压缩指令
```
core   0: 3 0x0000000080000020 (0x000003fe) x7  0x0000000080000000     # c.slli
core   0: 3 0x0000000080000022 (0x0003841b) x8  0xffffffff80000000     # sext.w
core   0: 3 0x000000008000002e (0x000053fd) x7  0xffffffffffffffff     # c.li
```

## 关键发现总结

1. **字段对齐:** Spike 日志使用固定宽度字段，便于程序解析
2. **寄存器格式:** `x<num>  <value>`（2空格分隔）
3. **内存格式:** `mem <addr>` 或 `mem <addr> <value>`
4. **PC格式:** `0x` + 16位十六进制（零填充）
5. **机器码:** 32位指令用8字符，16位压缩指令用4字符
6. **特权模式:** 提交行以数字标识（3=M, 1=S, 0=U）
7. **压缩指令:** 机器码显示为短格式，如 `(0x8082)`

## 参考命令

```bash
# 生成 fib 程序日志
riscv64-unknown-elf-gcc -march=rv64imafdc -mabi=lp64 -nostdlib \
    -T tests/bare-metal-riscv-test/linker.ld \
    tests/bare-metal-riscv-test/rv64i/fib.S -o fib.elf

# 运行并查看日志
spike --log-commits -l fib.elf

# 分析特定指令类型
spike --log-commits -l lw.elf 2>&1 | grep -E "(lw|sw)"
```
